# Commercial Landing Templates

Портфолио HTML-прототипов коммерческих лендингов.

## Шаблоны

1. Стоматология / имплантация зубов
2. Ремонт квартир под ключ
3. Аренда спецтехники
4. Банкротство физических лиц
5. Курсы английского языка

## Правила работы

- HTML-файлы в templates/ — reference prototypes.
- Не переписывать все шаблоны одной задачей.
- Правки делать точечно и коммитить по одному лендингу или одной группе изменений.
- Изображения хранить в assets/images/<landing>/.
- Скриншоты и референсы хранить в references/<landing>/.
